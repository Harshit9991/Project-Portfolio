# Pixbeat speaker: approved tag revision

Reference model, not a precision scan. Body 4.5 x 2.5 x 2.5 inches, excluding raised fixed strap.

Ivory clothes-style card and short cord at the right strap attachment. Supplied Pixbeat logo on both faces, converted into coloured mesh marks. Card pose is fixed, not cloth simulation.

GLB and model.json are generated from the same geometry. Dimensions in GLB are metres. Both logo faces are outward reading. No textures, music, pickup scene or animations.

Viewer: npm ci, npm run dev. Click the tag, or use Open Pixbeat experience. Dragging more than 6 pixels rotates without opening the popup. Popup is explicitly placeholder copy for placement review, not a finished venture narrative.

Generate: pip install -r requirements.txt; python generate_speaker.py. Needs DejaVuSansCondensed.ttf at the font path in script.

Original references included. Underside label is masked; dial reflection close-up excluded. No stock tag photo used. This approved revision is saved in the public Project-Portfolio repository. The hosted review remains private: https://files.instinct.com/4fn6vkgkckz2-your-speaker-in-3d
